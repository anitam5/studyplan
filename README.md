# Nauka-app
Jako uczeń chcę mieć aktywnego chat bota AI, żeby mógł pomagać w nauce
Jako uczeń chcę móc założyć konto, żeby plan tworzony przez AI był bardziej spersonalizowany
Jako uczeń chcę zaznaczać czy przerobiłam wybrany materiał, żeby widzieć progress i to co jeszcze muszę zrobić
Jako uczeń chcę widzieć poprzedni tydzień jako nieaktywny, żeby nie pogubić się w zadaniach
Jako uczeń chcę móc wybrać czy chcę widzieć plan dzienny, tygodniowy czy miesięczny, żeby widzieć zadania w czytelnym dla mnie formacie
Jako uczeń chcę mieć możliwość do jakiego rodzaju szkoły uczęszczam (liceum, technikum sz. branżowa), żeby system wiedział jak mniej więcej wymagająca jest nauka
Jako uczeń chcę dodać swoję dostępne godziny do nauki w zakładce 'Dostępność', więcej niż jeden odcinek czasowy w ciągu dnia, żeby plan ułożył się o wszystkich dogodnych dla mnie porach
Jako uczeń chcę mieć możliwość dodania w kalendarzu swoich zadań i obowiązków cyklicznych, żeby system nigdy nie uwzględnił tych godzin jako czas na naukę 
Jako uczeń chcę widzieć przyjazną dla oka stronę, żeby korzystanie z niej było przyjemne
Jako uczeń chcę bezpiecznie importować pliki, żeby moje dane były bezpieczne
