# studyplan
Co to jest: Aplikacja rozplanowująca naukę.

Dla kogo: Dla uczniów zarówno szkoły podstawowej, jak i średniej, którzy potrzebują pomocy w organizacji swojego czasu.

Jaki problem: Pomaga zapobiegać dezorganizacji i tłumaczy trudne zagadnienia.

Na koniec: Projekt dla uczniów promowany przez szkoły.

Zdjęcia materiałów dodane do zadań są kompresowane i przechowywane lokalnie w przeglądarce użytkownika. Nie są wysyłane na serwer ani do Eduo.
